brainsurgeon patch maker

Makes boot.nkp for your Sharp Brain from its own Windows CE image. For a PW-SH2, PW-SB1, PW-SH4, PW-A7300 or PW-G5300 image it recognises, it also adds that Brain's drivers. Everything happens in this browser tab: the image is never uploaded.

1. Your CE image

Boot the Brain once with the pwsh2-boot/dump-nk marker on the card. U-Boot then writes pwsh2-boot/nk-slot-A.bin or nk-slot-B.bin. Drop that file here. A full eMMC dump also works.

2. Your boot files

Drop your image above first.

    Unzip these onto the root of the card, keeping the folders. You can then delete nk-slot-*.bin from the card.

      3. launch.txt (optional)

      Tells bstart which program to start instead of Sharp's dictionary. The release card has one in each profile folder, pwsh2-boot/PROFILE/launch.txt. Save yours there to use it on one model, or as pwsh2-boot/launch.txt for models without their own.
